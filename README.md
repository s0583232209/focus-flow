FocusFlow is an attention-measurement web app: a Hebrew React client, a FastAPI backend, and MongoDB, with on-device camera scoring. Copy the env template and start the local stack with `cp .env.example .env` then `docker compose -f docker-compose.dev.yml up --build` (compose arrives in a later task). See [GIT_WORKFLOW.md](GIT_WORKFLOW.md) for branching, commits, and PRs, and [TASKS.md](TASKS.md) for the numbered team tasks.
