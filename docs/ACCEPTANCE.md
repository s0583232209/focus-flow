# ACCEPTANCE.md: בדיקת קבלה

עוברים על המסמך כאילו אתם הבודק: חלון בסתר, משתמש חדש, OBS. מי שלא כתב חלק בודק אותו.

- **Local:** מקומית, מתוך קבצי ההגשה בתיקייה ריקה (`docker compose up`).
- **Cloud:** ב-`https://<domain>`, ממחשב אחר ומטלפון.
- ממלאים בעמודות `V` או `X` + מספר Issue. כל `X` הוא Issue עם תבנית bug ותווית `acceptance` (T36).

**להכין מראש:**
- OBS → Sources → Media Source עם סרטון של אדם שמסתכל למצלמה (Loop) → Start Virtual Camera.
- סרטון נוסף בלי פנים.
- תוכן הדוגמה מ-`sample_content_for_testing` ב-PROJECT_INFO.
